# Bird Clicker

Небольшая браузерная clicker-игра на Phaser с адаптивным интерфейсом, анимациями и случайными звуковыми эффектами.

Игрок нажимает на птицу, получает очки и видит короткую tween-анимацию со всплывающим текстом. Проект разделяет игровые объекты, интерфейс и управление состоянием, поэтому его можно постепенно расширять до полноценной idle-игры.

## Возможности

- адаптивное игровое окно с `Phaser.Scale.FIT`;
- чёткий рендер на Full HD, 2K и 4K экранах;
- интерактивная птица с устойчивой к частым кликам tween-анимацией;
- всплывающие очки возле курсора;
- счётчик и FPS в режиме разработки;
- семь случайно выбираемых обработанных звуков;
- пул аудиообъектов для быстрых повторных нажатий;
- событийная связь между `GameManager` и интерфейсом;
- отдельные сцены загрузки и игры.

## Технологии

- Phaser 4.2.1;
- JavaScript и ES Modules;
- Vite;
- npm.

## Требования

- Node.js 20.19+ или 22.12+;
- npm 10+.

## Установка и запуск

```bash
git clone <URL-репозитория>
cd Clicker
npm install
npm run dev
```

После запуска Vite выведет локальный адрес приложения, обычно `http://localhost:5173`.

Для общего счётчика используется отдельный Go-проект `Clicker-Backend`. Сначала запустите PostgreSQL и API:

```bash
cd ../Clicker-Backend
docker compose up -d
go run ./cmd/server
```

Затем в другом терминале запустите frontend:

```bash
cd ../Clicker
npm run dev
```

По умолчанию frontend подключается к `http://localhost:8080`. Другой адрес можно задать переменной `VITE_API_URL` в локальном `.env`.

Опубликованная версия GitHub Pages использует production API `https://node.max.pandorum.fun/clicker-api`.

## Production-сборка

```bash
npm run build
```

Готовые статические файлы появятся в каталоге `dist`. Для локальной проверки production-сборки:

```bash
npm run preview
```

## Архитектура

`GameManager` оптимистично обновляет очки, пакетирует частые клики и уведомляет подписчиков через события. `ScoreApi` отправляет пакеты в Go API и получает общие обновления через SSE. Игровые объекты не изменяют UI напрямую.

`Bird` инкапсулирует обработку указателя, начисление очков, анимацию, всплывающий текст и воспроизведение звука.

`ScoreUI` отвечает только за заголовок, счёт и диагностический FPS.

Сцены разделяют начальную загрузку, загрузку ассетов и основной игровой процесс.

## Развёртывание

Проект является статическим приложением. Каталог `dist`, созданный командой `npm run build`, можно размещать на GitHub Pages, Cloudflare Pages, Netlify, Vercel или любом сервере со статической раздачей файлов.

Для публикации на GitHub Pages укажите команду сборки `npm run build` и каталог результата `dist`. В `vite.config.js` уже используется относительный `base: './'`, поэтому ассеты корректно загружаются из подпапки репозитория.
